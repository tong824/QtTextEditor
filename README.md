# 简单文本编辑器（QtTextEditor）

Qt 应用程序开发 · 实验二 —— 基于 Qt Widgets 的多窗口简单文本编辑器。

## 功能

- **文件**：新建、打开、保存、另存为、退出；未保存关闭时提示保存；异常文件给出提示。
- **编辑**：撤销、重做、剪切、复制、粘贴、全选；动作可用状态与当前选中文本/历史记录联动。
- **查找替换**：查找（向上/向下、连续查找、未找到提示）、替换当前、全部替换并统计次数。
- **格式**：字体选择、字体颜色、编辑器背景色、自动换行开关。
- **视图**：工具栏、状态栏、行号区域显示开关；定时自动保存（60 秒，可选开启）。
- **其他**：根据文档修改状态自动更新窗口标题（`*` 标记）；状态栏显示行列号与字符数；关于对话框。

## 工程结构

| 文件 | 说明 |
| --- | --- |
| `main.cpp` | 程序入口 |
| `mainwindow.h/.cpp` | 主窗口、菜单/工具栏/状态栏、文件与编辑逻辑 |
| `codeeditor.h/.cpp` | 继承 `QPlainTextEdit`，实现行号区域与当前行高亮 |
| `finddialog.h/.cpp` | 查找对话框 |
| `replacedialog.h/.cpp` | 替换对话框 |
| `aboutdialog.h/.cpp` | 关于对话框 |

## 构建

```bash
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH=<Qt6 安装路径>/mingw_64
cmake --build build
```
